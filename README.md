# Growthika Premium Website

A premium animated one-page website built with Next.js and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Vercel

1. Upload this folder to GitHub.
2. Import the repository into Vercel.
3. Keep the default Next.js settings.
4. Click Deploy.

## Easy edits

Main content is inside `app/page.tsx`:
- Services: `services`
- Audience types: `audiences`
- Portfolio concepts: `projects`
- Packages: `plans`
- FAQs: `faqs`

Global styling and animations are in `app/globals.css`.

## Important before launch

- Confirm the exact Instagram username/link.
- Replace concept portfolio blocks with real work later.
- Confirm package scope and ad-spend wording.
- Add a custom domain and business email when ready.
